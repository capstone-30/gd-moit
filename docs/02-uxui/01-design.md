# 디자인 기준 — 모잇

[문서 안내](../../README.md#관련-문서) · [요구사항](../01-func/01-common.md) · [기술 구조](../03-tech/01-architecture.md)

## 공통 규칙

수치·규격은 [토큰](../../frontend/tokens.css), 스타일은 [스타일](../../frontend/app/globals.css)이 원본이다.

- 파랑 강조색·중립 회색 바탕·시스템 한국어 글꼴과 모바일 단일 열 레이아웃을 기본으로 사용한다.
- 불투명 둥근 표면과 짧은 저농도 그림자로 입체감을 표현하고 선택은 선명한 안쪽 테두리로 구분한다(두꺼운 외곽 그림자·배경 블러 금지, 투명도는 그림자·사진 틴트·모달 배경에만 허용).
- 입력은 불투명 중립 표면·명확한 경계, 주요 행동은 강조색 채움, 보조 행동은 흰 표면, 위험 행동은 오류색·문구로 구분한다(색 단독 전달 금지). 입력 오류는 오류색 테두리와 함께 두꺼운 경계·경고 아이콘으로 표시한다.
- 주요 버튼·입력 높이 52px 이상, 상시 라벨·키보드 포커스, 본문 대비 4.5:1, 입력 경계·포커스 대비 3:1 이상을 유지하며, 자동 등장 효과는 쓰지 않고 모션 감소 시 이동 효과를 끈다.

### UX/UI 원칙

- 화면당 하나의 핵심 과업과 주요 행동(`제목 → 설명 → 주요 행동`)에 집중한다.
- 공통 토큰·컴포넌트·용어·동사형 버튼명을 일관되게 사용하며, 모든 빈 결과·오류·참여 불가·제출 대기 상태에 이유와 복구 경로를 제공한다.
- 날짜에 맞는 후보 교시가 없으면 다른 날짜 선택을 안내한다. 일괄 등록 실패는 문제 행과 수정할 입력을 표시하고 전체 입력을 보존한다. 지출일 입력은 학교 기준 오늘까지 허용한다.
- 학생 주요 화면은 서로 다른 탭 제목을 제공한다. 공지·코멘트·서류 시각은 학교 시간대로 표시하며, 내부 링크는 새 창 아이콘을 사용하지 않는다. 상세 조회의 권한·삭제 오류에는 해당 역할의 목록 복귀 링크를 제공한다.
- 페이지를 넘기면 목록 바로 위 제목으로 포커스와 스크롤을 옮긴다. 제출 중 비활성으로 포커스를 잃으면 처리 후 누른 버튼으로 되돌린다.

## 공통 화면 틀

- 고정 상단 중앙에 프로젝트명, 좌우에 동일 조작 영역(왼쪽은 하위 화면 `<` 뒤로가기 전용, 기관 모임 상세는 소속 프로젝트로 복귀)을 두며 본문·포커스 가림을 방지한다.
- 하단 내비게이션과 고정 작업 버튼은 [플로팅 필 탭 바](#플로팅-필-탭-바)를 따르며, 시간표·서류 등 밀집 영역에는 장식 그림자를 넣지 않는다(입력 경계는 `border`, 구분선은 `rule` 토큰 사용).

### 팝업

- 화면 중앙(최대 폭 640px, 좌우 여백 16px, 공통 표면·곡률·배경 음영)에 열며 상단 제목·닫기, 내부 스크롤, 포커스 가두기, Esc 닫기, 실행 버튼 포커스 복귀를 제공한다.
- 미저장 공지·일괄 등록을 닫을 때 공통 확인 창을 사용한다. 취소에 초기 포커스를 두며 Enter와 Esc는 입력을 보존한다.

## 화면 구성

상단 브랜드 → 제목·설명 → 기능 영역 순서로 구성하며([학생](../01-func/02-student.md#내비게이션프로필) · [대학 담당자](../01-func/03-institution.md#내비게이션프로필) 메뉴), 정상·로딩·빈 결과·실패·재시도·이탈 확인·충돌 시 입력 보존을 제공한다.

### 학생 홈

[홈 요구사항](../01-func/02-student.md#학생-홈)의 바로가기·시간 요약 카드를 데스크톱 좌우·모바일 상하로 두고, 아래에 모임 미리보기 카드를 독립 상태로 표시한다.

### 모임 탐색

상단 유형 필터(선택 즉시 1페이지 적용, [S-FR-03](../01-func/02-student.md#기능) 정렬)와 모임 카드를 배치하며, 빈 결과 시 전체 보기·모임 개설로 안내한다. 현재 학기 가능 시간을 등록하지 않았으면 목록 위에 등록 안내와 가능 시간 링크를 둔다. 모임 관리는 자율·대학 주관 모임 목록과 각 페이지 이동을 분리한다.

### 모임 카드

- 유형 배지·우측 상단 인원 원(채움/빈 원, 보조 기술 전달)·주제·장소·일정을 표시하고 카드 전체를 상세 링크로 사용한다(주관 모임 선택 조작은 분리).
- 참여 불가·비겹침 카드는 보조 기술에서 서로 구분해 읽히고, 흐린 표면·약한 그림자로 구분하되 대비·키보드 접근·상세 조회를 유지한다. 카드 최소 폭 400px 기준 2열·1열로 자동 전환한다.

### 대학 주관 모임

- 템플릿·프로젝트·관리는 동일한 세로형 포스터 카드 규격을 공유한다(학생 홈에는 별도 포스터 카드 미표시).
- 프로젝트 생성은 가로 스크롤 템플릿 카드 선택과 하단 고정 패널(좌측 프로젝트명 입력·우측 생성 버튼)로 구성한다. 좁은 화면에서는 카드 표지를 줄여 첫 화면의 템플릿 카드가 패널에 가리지 않게 한다.
- 관리 화면은 프로젝트 카드(`유형·제목·모임 수`) 선택 시 소속 모임 목록으로 이동하며, 소속 모임 제목 우측에 프로젝트 수정·삭제와 모임 등록 팝업 버튼을 둔다.

### 공지·제출 현황

권한·배포·제출 요구는 [공지 정책](../01-func/03-institution.md#공지제출-요구)을 따른다.

- 공지 목록은 `(배지) 제목` 한 줄로 표시하고 클릭 시 상세 팝업(상단 수정·삭제 아이콘 포함)을 연다. 우측 상단 아이콘으로 현재 화면 범위의 작성 팝업을 연다.
- 제출 요구 공지는 `서류 제출` 배지와 우측 완료/대상 수(모임 화면은 원 표시 포함)를 표시하며 클릭 시 제출 현황·자료 열람 팝업을 연다.

### 시간표

상단 요일·좌측 교시/시각 고정 축 표(좁은 화면 가로 스크롤)에 요일 전체/개별 선택, 체크+색상 강조, 선택 교시 수를 표시한다.

### 인증·개설

- 랜딩은 소개·유형·로그인 진입을, 로그인은 `이메일 → 인증번호`(요약·변경·남은 시간·재발송) 단계 입력만 표시한다.
- 모임 개설은 단일 모임 카드 안에서 유형(좌)·인원(우)·제목·검증 장소·미정 일정 안내 팝오버를 입력하고 하단 개설 버튼으로 제출한다.

### 프로필

- 학교·이메일 아래 세로 메뉴(`가능 시간 · 내 정보 · 차단 · 계정`, 담당자는 계정 관리)에서 각 항목을 [공통 팝업](#팝업)으로 연다([설정 직접 링크](../01-func/01-common.md#내비게이션프로필) 지원).
- 가능 시간 팝업은 상단 상태(저장·미저장·저장 중), 시간표·이미지 불러오기(눈금 형식 선택 후 업로드 활성), 하단 `변경 사항 저장`을 두며 미저장 닫기 시 확인 창(`계속 변경` 기본 포커스 · `삭제`)을 띄운다.
- 내 정보는 동의 전 입력 제한 사유를 안내하고 관심 주제를 태그로 입력·저장한다.
- 기존 선택 정보의 동의를 철회해 저장할 때 표시 이름·학과·입학 연도·관심 주제 삭제를 확인한다. 저장 안내는 값 변경에 따른 폼 재마운트 후에도 유지한다.

### 함께 가능한 시간

시간표를 읽기 전용으로 재사용해 전원 가능 교시만 체크·강조하고 제목 옆에 전체 교시 수를 표시한다(만료 학기는 텍스트 표시).

### 모임 상세

- 일반 모임은 `확정 상태 → 참여자(클릭 시 안전 메뉴 팝업) → 조율 → 코멘트` 순서며 회고 모임은 [회고 모임 정책](../01-func/02-student.md#모임-분류회고-모임)에 따라 게시판을 먼저 둔다.
- 나가기는 확인 팝업으로 열며 참여 불가 시 사유와 가능 시간 설정·탐색 링크를 안내한다. 참여할 수 있는 모임에서 모임 학기 가능 시간을 등록하지 않았으면 참여 패널 위쪽에 등록 안내를 둔다.
- 개설자는 참여자 안전 메뉴에서 확인 체크 후 개설자를 위임하고, 참여 패널에서 나가기 대신 위임 안내와 모임 닫기 팝업(삭제 범위 확인 후 모임 관리로 이동)을 사용한다. 진행 중인 제안에는 개설자에게만 제안 철회를 둔다.
- 위임·철회 성공 시 팝업을 닫고 상태 영역 아래 결과 안내로 포커스를 옮기며, 이후 모임 상태가 바뀌면 안내를 숨긴다.

## 플로팅 필 탭 바

- 하단 메뉴는 불투명 캡슐(`--radius-pill`, `999px`)에 아이콘·라벨 중앙 정렬과 브랜드색 선택 배경을 사용한다(좁은 화면의 담당자 메뉴는 `생성`·`관리`로 축약하되 접근성 전체 이름 유지).
- 하단 고정 작업 바도 필 곡률·내부 여백 12px·넓은 그림자를 사용하며 안전 영역·본문 여백을 확보한다.
