# 학생 요구사항

[공통 요구사항](../../spec.md)의 인증·개인정보·출시 조건을 함께 적용한다. 대학 주관 모임의 배정·일정·서류 제출은 [기관 요구사항](institution.md#대학-주관-모임제출-서류)을 따른다.

## 기능

인증 요구사항 C-FR-01은 [공통 인증 정책](../../spec.md#인증접근-권한)을 따른다.

| ID | 구현 조건 |
| --- | --- |
| S-FR-01 | 학기별 요일×교시 가능 시간 수정·재사용. 모임별 가능 시간 변경은 제공하지 않는다. 본인의 미만료 다른 학기에서 요일·교시 번호·시작/종료가 같은 교시만 불러와 제외 수 안내·검토 후 저장; 원본·보관 기한 불변. |
| S-FR-02 | 주제·유형·공개 장소·정원으로 시간 미정 모임 개설. 검증된 캠퍼스 내/주변 장소 목록만 선택. 개설자 포함 2~4명, 기본 3명 이상·2명 명시 선택. |
| S-FR-03 | 모임 찾기는 검색창 없이 유형으로 탐색하며 미참여 모임을 시간 겹침 여부와 관계없이 표시한다. 본인 가능 시간과 겹치는 모임을 전체 목록에서 먼저, 겹치지 않는 모임을 뒤에 배치한다. 참여 불가·시간 비겹침 모임도 상세 조회를 허용하며 표시는 [모임 카드](../design.md#모임-카드)를 따른다. 그룹 안에서는 최신 개설순이다. 승인 없이 정원 내 즉시 참여하며 중복 참여로 인원 증가 금지. |
| S-FR-04 | 상세에서 참여자·가능 시간 교집합 표시. |
| S-FR-05 | 개설자가 교집합 시간 확정; 교집합이 없으면 대안 제안·전원 수락. 세부 상태 전이는 아래 조율 규칙 적용. |
| S-FR-06 | 참여자 전용 새로고침 코멘트로 자기소개·장소 변경·지각·취소 연락. |
| S-FR-07 | 모임/사용자 신고·차단·개설자의 내보내기·차단 해제. 상대 모임 숨김; 공동 모임에서 차단자가 개설자면 상대 내보내기, 아니면 본인 나가기. |

## 모임 분류·회고 모임

- 일반 모임은 모각공·런치챗·커피챗이다. 대학 주관 모임은 활동 보고서·활동비 사용 내역서 기능이 추가된 특수 모임이며, 회고 모임은 회고 글 공유를 중심으로 구성한 특수 모임이다. 목록·상세의 모임 뱃지는 `모각공`·`커피챗`·`런치챗`·`회고`·`대학 주관` 중 하나로 표시한다.
- 회고 모임은 참여자 전용 회고 게시판에서 경험·배움·다음 시도를 글로 공유한다. 게시판을 일정·참여 관리보다 먼저 표시하며 작성·글 목록·새로고침·페이지 이동을 제공한다. 참여·시간 조율은 [조율 규칙](#조율-규칙)을 따른다.
- 회고 글은 기존 코멘트 API를 사용한다. 공개 범위는 [S-FR-06](#기능), 보관·삭제는 [개인정보 정책](../../spec.md#개인정보-정책), 글자 수 제한은 코멘트 입력 검증을 따른다.

## AI 작성 지원

연동 대기 중인 추가 요구사항이다. 제공자 확인과 구현 재개 조건은 [남은 작업](../../plan.md#남은-작업)을 따른다.

- 모임 대화 주제 제안: 참여자가 요청하면 해당 모임의 주제·유형을 바탕으로 첫 대화 질문과 후속 질문을 생성한다.
- 회고 작성 도우미: 본인이 입력한 경험·배운 점·다음 시도를 회고 초안으로 정리한다. 입력하지 않은 사실을 추가하지 않도록 생성하며, 사용자가 검토·수정 후 기존 게시 기능으로 직접 게시한다.
- 두 기능은 선택적으로 사용한다. 다른 참여자의 글·프로필·이메일·개별 가능 시간은 전송하지 않는다. 생성 실패·사용 한도 도달 시 입력을 보존하고 기존 모임·회고 기능을 계속 사용할 수 있다.
- 외부 AI 전송 전 전송 항목·제공자·처리 목적을 안내한다. 제공자의 보관·학습 사용·처리 경로를 확인하고 개인정보 고지에 반영한 뒤 실제 연동을 활성화한다. 생성 초안은 별도 영구 보관하지 않으며 게시한 회고는 기존 회고 정책을 따른다.

## 내비게이션·프로필

로그인한 학생의 하단 메뉴는 다음 순서로 제공한다.

| 메뉴 | 경로 | 역할 |
| --- | --- | --- |
| 홈 | `/home` | 학생의 첫 화면 |
| 모임 찾기 | `/meetings` | 미참여 자율 모임 탐색·참여 |
| 모임 열기 | `/meetings/new` | 자율 모임 개설 |
| 모임 관리 | `/meetings/manage` | 본인이 개설·참여 중인 모임과 배정된 대학 주관 모임 통합 조회 |
| 프로필 | `/profile` | 학기 가능 시간·선택 정보·차단·계정 관리 |

- 모임 개설·참여 후 `/meetings/manage/:id`로 이동한다. 상세에서 일정·조율·코멘트, 대학 공지·서류, 회고 게시판을 유형에 맞게 제공한다. 관리 화면에 탐색 필터·개설 폼을 표시하지 않는다.
- 기존 `/meetings/institution`은 모임 관리로 연결하며, 주관 모임 상세에서도 모임 관리로 돌아간다.

## 학생 홈

모임 찾기·개설 바로가기, 현재 학기 가능 시간 요약, 최근 개설된 참여 자율 모임·배정된 대학 주관 모임을 각각 최대 2개 표시한다. 전체 목록은 모임 관리에서 확인하며 홈에서 전체 건수나 참석 통계를 추정하지 않는다.

## 시간표 목업

- 데모 교시는 월~금 1~12교시로 구성한다. 1교시는 09:30~10:20이며 이후 50분 수업·10분 쉬는 시간 간격으로 12교시 20:30~21:20까지 제공한다.
- 프로필 시간표에서 이미지 선택·미리보기·예시 공강 자동 표시 목업을 제공한다. 실제 이미지 인식 대신 고정 예시를 사용한다고 명시하고 적용 취소·직접 수정·검토 후 저장을 제공한다. 이미지는 브라우저에서만 처리하며 서버로 전송·보관하지 않는다.

## 조율 규칙

- 가능 시간은 공강·상시 승낙이 아니다. 확정/제안 날짜는 오늘부터 28일 이내이며 교시 요일과 일치해야 한다. 별도 종료 상태는 없다.
- 제안 수락 중 신규 참여 금지. 참여자·가능 시간 변경 시 제안 취소.
- 교집합 확정은 학기 가능 시간 변경으로 확정 교시가 교집합에서 빠지면 미정 복귀한다.
- 대안 전원 수락은 해당 날짜·교시에 대한 동의다. 학기 가능 시간을 수정하지 않으며 이후 가능 시간 저장으로 확정 교시가 빠져도 동의·확정을 유지한다. 정책 미확정을 이유로 변경을 거부하지 않는다.
- 확정 방식과 무관하게 참여자가 1명이 되면 날짜·교시를 비우고 미정 복귀한다. 대안 확정은 2명 이상이면 남은 동의를 유지한다.
- 확정 모임 신규 참여는 해당 교시가 본인 가능 시간에 포함될 때만 허용하며 기존 수락을 승계하지 않는다. 미정 복귀 후에는 새 조율이 필요하고 이전 동의를 다른 날짜·교시에 재사용하지 않는다.
