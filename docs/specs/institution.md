# 기관 요구사항

[공통 요구사항](../../spec.md)의 인증·개인정보·출시 조건을 함께 적용한다. 이 문서는 대학 담당자 기능과 배정된 학생의 주관 모임 이용 정책을 다룬다.

## 내비게이션·프로필

대학 담당자의 하단 메뉴는 다음 순서로 제공한다.

| 메뉴 | 경로 | 역할 |
| --- | --- | --- |
| 홈 | `/institutions` | 주요 기능 바로가기 |
| 프로젝트 생성 | `/institutions/projects/new` | 활동 템플릿 선택·프로젝트 등록 |
| 프로젝트 관리 | `/institutions/meetings` | 프로젝트별 모임·공지·제출 서류 관리 |
| ESG 성과 | `/institutions/esg` | ESG 영역별 합성 활동 현황 시연 |
| 프로필 | `/institutions/settings` | 담당자 계정 관리 |

- 프로젝트 생성은 전용 화면에서 제공하고 생성 후 프로젝트 관리로 이동한다.

## 기관 시연

- `/institutions/esg`에서 인증된 대학 담당자에게 ESG 성과 시연을 제공한다. 환경(E)·사회(S)·거버넌스(G) 주제의 고정 합성 모임을 표시하며 실제 ESG 평가·환경 효과로 해석하지 않도록 안내한다. 환경 실천, 학습·멘토링, 공동체 운영을 시연용 주제로 분류하며 각 모임은 한 영역에만 속한다.
- 개설 월·유형 필터에 따라 모임 수·확정 수·참여 건수·정원 충원율, 영역별 참여 현황과 주제별 현황을 함께 갱신한다. 탄소 감축량·폐기물 수거량·ESG 점수 등 측정 근거가 없는 지표는 제공하지 않는다. 결과 없음은 0과 빈 상태로 표시한다.
- 참여 건수는 모임별 인원의 합이며 고유 인원·실제 참석을 뜻하지 않는다. 충원율은 참여 건수 / 정원 합계다.

## 대학 주관 모임·제출 서류

### 프로젝트·학생 배정

#### 프로젝트 생성·템플릿

- 프로젝트별 소속 모임 경로는 `/institutions/meetings/projects/:id`다. 기존 프로젝트 미지정 모임은 전체 모임 링크로 계속 조회한다. 목록 배치와 선택 동작은 [디자인 기준](../design.md#대학-주관-모임)을 따른다.
- 활동 생성은 ‘빈 템플릿으로 시작’을 첫 번째로 배치하고 [활동 템플릿 원본](../../shared/hosted-activities.ts)의 진입점을 제공한다. 생성 화면에서 프로젝트명을 입력하고 선택한 템플릿으로 생성한다. 담당자는 보관 중인 본인 프로젝트 제목을 프로젝트 관리에서 언제든 수정할 수 있으며 동시 수정 충돌 시 입력을 보존한다.
- 포스터의 일정·인원·혜택·외부 신청 절차는 참고 자료이며 앱의 배정·인원·서류 정책을 대체하지 않는다. 노출 위치는 [디자인 기준](../design.md#대학-주관-모임)을 따른다.
- 템플릿별 기본 요구 서류는 [활동 템플릿 원본](../../shared/hosted-activities.ts)에서 관리한다. 생성된 모임에 기본 제출 안내 공지 카드를 게시한다. 빈 템플릿은 기본 제출 요구가 없다. 기존 일반 프로젝트·제출 자료는 보존한다.
- 담당자는 현재 학교·학기에 프로젝트 이름·활동 유형을 등록하고, 본인 프로젝트 안에서 모임별 이름·학생 구성을 입력해 한 번에 1~20개 주관 모임을 생성한다. 구성 검증에 하나라도 실패하면 전체 생성을 취소한다. 프로젝트 미지정 모임의 신규 생성은 제공하지 않으며 기존 모임은 계속 조회·관리한다. 프로젝트 목록은 본인 담당자만 조회하며 학생에게는 배정된 모임의 프로젝트 이름·활동 유형을 표시한다.

#### 보관·학생 배정

- 프로젝트는 생성 후 120일 보관하며 소속 모임의 보관 기한은 프로젝트 만료일을 넘지 않는다. 만료 즉시 조회·생성을 차단하고 일일 삭제 시 소속 자료와 함께 삭제한다. 담당자 탈퇴 시 프로젝트도 삭제한다.
- 담당자는 현재 학교·학기의 모임 이름과 학생 구성(2~4명)만 등록한다. 같은 학교에 가입한 학생의 학교 이메일로 배정하며 중복·다른 학교·담당자 계정은 허용하지 않는다. 입력 이메일은 구성 확인에만 사용하고 조회 응답에 공개하지 않는다. 담당자는 인원에 포함하지 않으며 학생 자율 모임과 별도로 관리한다.

### 일정·모임 삭제

- 담당자는 본인의 보관 중인 프로젝트를 삭제할 수 있다. 확인 후 프로젝트·소속 모임·참여·공지·제출 자료를 같은 트랜잭션에서 삭제하고 복구용 삭제 목록에 프로젝트 ID를 기록한다. 학생·다른 담당자는 삭제할 수 없다.

- 담당자는 본인이 주관하는 모임을 삭제할 수 있다. 삭제 확인 후 모임·참여·공지·전체 제출 자료를 같은 트랜잭션에서 삭제하고 복구용 삭제 목록에 기록한다. 학생과 다른 담당자는 삭제할 수 없다.
- 학생은 배정된 주관 모임만 조회한다. 배정된 학생 누구나 활동일·교시·검증된 공개 장소를 설정하며 담당자는 이를 설정할 수 없다. 날짜 검증은 [조율 규칙](student.md#조율-규칙)을 따르고 동시 변경은 버전 충돌로 처리한다. 서류가 하나라도 제출된 뒤에는 일정·장소를 변경할 수 없다.

### 공지·제출 요구

공지 작성은 담당자의 프로젝트 화면과 모임 상세에서 제공하고, 수정·삭제는 프로젝트 화면에서 제공한다. 표시·조작 방식은 [디자인 기준](../design.md#공지제출-현황)을 따른다.

- 프로젝트 화면에서 작성한 공지는 게시 시점의 보관 중인 전체 소속 모임에 게시하며 대상을 선택할 수 없다. 모임 상세에서 작성한 공지는 해당 모임에만 게시한다. 함께 게시한 공지는 프로젝트 목록에 하나로 표시하고 제목·본문·제출 설정을 함께 수정한다. 기존 모임별 공지도 해당 프로젝트에서 수정하며 배포 대상은 수정하지 않는다.
- 삭제 확인 후 같은 프로젝트에 함께 배포한 공지를 삭제하고 복구용 삭제 목록에 기록한다. 모임과 제출 자료는 유지하며 남은 공지의 마지막 제출 설정으로 요구 서류를 재계산하고, 설정 공지가 없으면 제출 요구를 해제한다. 수정·삭제는 버전 충돌 시 최신 상태를 확인한 뒤 다시 실행한다. 수정 입력은 보존한다.
- 공지 작성 시 서류 제출 요구 변경을 선택하면 활동 보고서·활동비 사용 내역서를 각각 활성화·해제하며 해당 공지 카드에 설정을 표시한다. 일반 공지는 제출 요구를 변경하지 않는다.
- 현재 제출 요구는 게시 순서상 마지막 제출 설정 공지를 따르며, 과거 공지 수정으로 이후 설정을 덮어쓰지 않는다.
- 최신 설정과 공지 게시·수정을 같은 트랜잭션에서 반영하며 기존 제출 자료는 삭제하지 않는다. 권한이 없거나 만료된 모임이 포함되면 전체 게시를 취소한다. 공지는 해당 모임 학생과 주관 담당자만 조회하며 모임과 함께 만료·삭제한다.

### 서류 제출·열람

- 담당자는 제출 요구가 있는 공지에서 참여자별 제출 상태와 자료를 확인한다. 표시 방식은 [디자인 기준](../design.md#공지제출-현황)을 따른다. 상태는 해당 공지가 요구한 서류와 현재 제출 자료로 판단하며 공지별로 별도 제출을 저장하지 않는다. 일반 공지·제출 요구 해제 공지에는 상태를 표시하지 않는다. 해제 전 자료도 기존 제출 공지에서 열람한다.
- 참여 학생은 활동일부터 활성화된 서류만 제출한다. 활동 보고서는 활동 내용·성과, 활동비 사용 내역서는 지출일·사용 목적·원 단위 금액을 입력한다. 두 서류는 각각 제출 상태를 보관하며 요구된 서류가 모두 제출되어야 완료로 표시한다. 요구가 없으면 제출 대상 없음으로 표시한다. 해제된 서류는 새 제출을 차단하고 이미 제출한 자료의 열람·다운로드는 유지한다.
- 지출이 없으면 빈 목록과 합계 0원으로 제출한다. 미래 지출일은 허용하지 않는다.
- 만료 전 재제출은 기존 내용을 대체하며 수정 시각을 표시한다. 동시 수정 충돌 시 입력을 보존하고 최신 상태를 조회한 뒤 다시 제출한다.
- 제출 자료는 본인과 해당 모임 주관 담당자만 조회하고 활동 보고서·활동비 사용 내역서를 각각 CSV로 내려받을 수 있다. 담당자는 참여 순서 번호별 제출/미제출 현황을 확인한다. 다른 담당자·비참여 학생·다른 참여 학생에게 제출 내용을 공개하지 않는다. CSV의 사용자 입력은 수식 실행을 막는다.
- 참여 취소 시 확인 후 본인의 제출 자료를 함께 삭제한다. 활동비 사용 내역은 기록·수신 기능이며 지급·승인·정산은 포함하지 않는다.

### 보관·탈퇴

- 주관 모임·참여·공지·제출 자료는 활동일로부터 30일, 일정 미정은 생성 후 90일, 생성 후 최대 120일 보관한다. 만료 즉시 조회·다운로드에서 제외하고 일일 삭제 대상에 포함한다. 학생 탈퇴 시 본인의 참여·서류, 담당자 탈퇴 시 주관 모임·전체 서류를 함께 삭제한다.
