## 검증 전략

- 인증·권한·입력 경계·조율·동시성·삭제와 화면 제출·상태·접근성을 검증한다(단순 문구·CSS·호출 횟수 고정 지양).
- 실행 명령·DB 분리는 [README 테스트](../../README.md#테스트), 최종 판정은 [완료 기준](../01-func/01-common.md#완료-기준)을 따른다.

## 아키텍처 경계 검증

[architecture.test.ts](../../backend/tests/architecture.test.ts)로 domain/application의 외부 의존·직접 I/O·SQL·환경 접근 금지([아키텍처와 경계](../03-tech/01-architecture.md#아키텍처와-경계))와 메일 실패 시 OTP 폐기, 삭제 전달 실패 시 재시도, 감사 실패 시 역할 변경 차단을 검증한다.

## 화면 검증

데스크톱 `1920×1080`, 모바일 `360×784` CSS px 뷰포트에서 가로 넘침·메뉴 겹침·긴 라벨·폼·조작 영역을 확인한다.

## API 계약 검증

API 변경 시 [REST API 계약](../03-tech/01-architecture.md#rest-api-계약)의 정상·거부·오류·헤더 계약을 검사하고 OpenAPI·라우터·DTO를 대조한다.

## 최신 판정

자동 검사와 조율·로그인 화면 검증은 2026-11-16 [이슈 #2](https://github.com/capstone-30/gd-moit/issues/2) 변경 후 실행했다. 프로필·기관 입력의 수동 검증은 2026-11-13 결과다. 내용이 누락된 점검 항목과 근거 없는 과거 집계는 사용자 요청에 따라 추적 범위에서 제외한다.

| 검사 | 현재 결과 |
| --- | --- |
| 자동 검사 | 별도 로컬 `_test` DB에서 실제 PostgreSQL 계약을 포함한 백엔드 62건·프런트엔드 44건 통과, 생략 0건. 타입·프로덕션 빌드·문서 링크 검사 통과. 참여자 거절·교집합/대안 확정 취소·기존 동의 무효화·권한·CSRF·ETag·재요청, 역할별 복귀 경로 허용 목록과 목적지 헤더 덮어쓰기를 검사했다 |
| 조율·로그인 | 별도 합성 `_demo` DB에서 비로그인 모임 관리 접근 → OTP 인증 → 원래 화면 복귀를 확인했다. 개설자 확정 취소와 이미 수락한 참여자의 거절 후 미정 복귀·팝업 닫힘·결과 안내 포커스를 확인했다 |
| 프로필 | 별도 합성 `_demo` DB의 학생으로 기존 정보 철회 저장 시 삭제 범위·취소 초기 포커스·Enter/Esc 입력 보존을 확인했다. 실제 값 변경·저장·재조회 후 성공 안내를 확인했다 |
| 기관 입력 | 일괄 등록의 잘못된 학생 행 안내·입력 보존, 공지와 일괄 등록의 취소 초기 포커스·Enter/Esc 입력 보존을 확인했다. 공지 폐기 확정 후 재작성 시 빈 입력을 확인했다 |
| 반응형 | 브라우저 360×784·1920×1080에서 기관 확인 창과 입력 폼을 확인했다. 측정한 문서 폭은 뷰포트를 넘지 않았다 |
| 조율 반응형 | 거절 후 결과 화면을 360×784·1920×1080에서 확인했으며 문서 폭은 뷰포트를 넘지 않았다 |
| 자동 회귀 범위 | OTP 오입력·만료·폐기, 일괄 등록 오류 행·전체 롤백·응답 비공개 필드, 비겹침 카드 접근성 이름, 빈 교시 안내, 지출일 상한, 학교 시간대 경계, 상세 오류 복귀 링크를 검사했다 |

실기기·화상 키보드·스크린리더 및 모든 화면의 포커스 순서는 미확인이다. 대상 기기와 구체적인 재현 조건 확보 후 [화면 검증](#화면-검증)을 재개한다. 남은 화면 검증은 [남은 작업과 리스크](../03-tech/01-architecture.md#남은-작업과-리스크)를 따른다.
