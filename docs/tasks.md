# 작업 현황

실제 구현 상태·검증 증거의 원본이다. 실행 작업은 [GitHub Project](https://github.com/orgs/capstone-30/projects/1)에서 관리한다.

## 현재 상태

- AWS 저장소/전달 수신부·스케줄러·실패 경보의 실제 연결은 미완료다.
- [대안 확정 후 시간 변경 정책](spec.md#구현-정책-확인-대기)은 미확정이다. 해당 시간 변경은 기존처럼 503·전체 롤백으로 차단한다. 실제 학교·도메인·학기·교시·장소·연락처는 추정하지 않았다.

## 검증

- 미검증: 브라우저 탈퇴/개설자 내보내기·전체 키보드 흐름·대상 기기/실사용자 흐름, 미확정 정책의 마지막 수락/시간 변경 경합, 실제 SES 수신·AWS 백업/복원·삭제 전달/감사 저장·배포 URL.

## 남은 작업

실제 운영 설정·출시 검증·AWS 배포·인력 결정은 GitHub Project의 SB-01~05를 따른다. [Figma](plan.md#개정-화면-설계)·아이콘·디자인 CSS를 보존했으며 여유시 기능은 [요구사항 범위](spec.md#범위)에 따른다.
