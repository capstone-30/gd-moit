# 모잇 디자인 기준

## 방향

Modern minimal. 기존 모잇 색상을 유지하면서 큰 고딕 제목, 짧고 친근한 안내, 충분한 여백, 명확한 행동 버튼으로 탐색과 조율을 돕는다.

## 공통 체계

- 색상·대비·로고 원본: [브랜드](brand.md). 구현 토큰 원본: [tokens.css](../frontend/tokens.css). 값을 이 문서에 중복하지 않는다.
- 제목·본문: 한국어 시스템 고딕. 크기와 굵기로 위계를 나누고 제목에는 명조를 쓰지 않는다.
- 간격: 4px 기반 토큰. 입력과 주요 버튼은 높이 52px 이상, 둥근 모서리. 라벨은 항상 표시한다.
- 주요 행동은 브랜드 파랑, 보조 행동은 밝은 바탕. 위험 행동은 오류색과 명시적인 문구를 함께 쓴다.
- 동작은 짧은 버튼 누름만 사용한다. 포커스는 즉시 표시하고 모션 감소 설정에서는 이동 효과를 끈다.

## 화면 구성

- 앱: 단일 작업 흐름(Workbench). 공통 상단 내비게이션, 제목·설명, 기능별 밝은 표면. 모바일은 한 열, 넓은 화면에서는 목록·상세에 보조 영역을 배치한다.
- 목록: 주제 검색, 유형 선택, 시간 겹침 조건, 모임 목록. 실제 인원·장소·시간 상태와 상세 진입을 구분한다.
- 인증·개설: 좁은 폼, 명확한 라벨과 전체 너비 주요 버튼.
- 프로필·상세: 시간표와 각 작업을 섹션으로 나누고 안전 메뉴는 펼쳐서 접근한다.
- 개인정보: Long Document. 충분한 행간과 항목 구분으로 읽기 쉽게 구성한다.
- 로딩·빈 결과·실패: 공통 표면 안에서 상황과 다음 행동을 설명한다. 가짜 모임·운영값을 표시하지 않는다.

## 구현

[공통 스타일](../frontend/app/globals.css)과 [공통 컴포넌트](../frontend/app/components/client.tsx)를 모든 화면에서 재사용한다. 별도 디자인 라이브러리·폰트 다운로드는 추가하지 않는다.
