# 디자인 기준

## 공통 규칙

색·크기·곡률·여백·글꼴의 값은 [토큰](../frontend/tokens.css), 적용 방식은 [스타일](../frontend/app/globals.css)을 원본으로 관리한다. 이 문서는 화면 구성과 상호작용 기준을 설명한다.

- 파랑 강조색·중립 회색 바탕·시스템 한국어 글꼴을 사용한다. 모바일은 한 열을 기본으로 하고 제목·설명·주요 행동의 위계를 분명히 한다.
- 카드·메뉴·팝오버는 흰 불투명 표면·밝은 안쪽 가장자리·은은한 그림자를 공유한다. 배경 블러는 쓰지 않으며 그림자·사진 틴트·대화상자 바깥 배경에만 투명도를 허용한다.
- 입력은 불투명한 옅은 중립 표면과 명확한 경계를 사용한다. 주요 행동은 강조색 채움, 보조 행동은 흰 표면, 위험 행동은 오류색과 문구로 구분한다. 선택·오류는 색만으로 전달하지 않는다.
- 입력·주요 버튼 높이는 52px 이상이다. 상시 라벨·키보드 포커스를 제공하고 본문 대비 4.5:1, 입력 경계·포커스 대비 3:1 이상을 유지한다. 입력 오류는 input·select·textarea에 같은 기준으로 표시한다.
- 자동 등장 효과는 쓰지 않는다. 짧은 누름 반응을 사용하며 모션 감소 설정에서는 이동 효과를 끈다. 320·375·414·768px에서 가로 넘침과 조작 영역을 확인한다.

## 공통 화면 틀

- 고정 상단의 프로젝트명을 중앙에 두고 좌우에 같은 조작 영역을 확보한다. 왼쪽은 상세·하위 화면의 돌아가기 버튼에만 사용한다. 본문·앵커·키보드 포커스가 상단에 가리지 않게 한다.
- 하단 내비게이션은 화면 가장자리에서 띄운 불투명 캡슐로 표시한다. 본문 여백과 기기 안전 영역을 확보하고 아이콘·한 줄 라벨을 중앙 정렬한다. 현재 메뉴는 배경·글자색·굵기로 구분하며 상단 표시선은 쓰지 않는다.
- 메뉴와 강조 영역은 같은 `--radius-navigation` 윤곽을 사용한다. hover에도 같은 윤곽을 유지하고 키보드 포커스는 메뉴 안쪽에 표시한다. 공통 규격을 바꿀 때 기능별 카드 비율·동작을 유지한다.
- 시간표·서류 등 정보가 밀집한 영역에는 장식 그림자를 넣지 않는다. 입력 경계는 `border`, 장식 구분선은 `rule` 토큰을 사용한다. 별도 폰트·디자인 라이브러리는 추가하지 않는다.

### 팝업

접고 펼치는 토글 대신 버튼으로 팝업을 연다. 학생·담당자 화면에 같은 기준을 적용한다.

- 화면 가로·세로 중앙, 최대 폭 640px·좌우 여백 16px. 내비게이션과 같은 곡률·표면·그림자와 공통 배경 음영을 사용한다.
- 제목·닫기는 상단에 두고 긴 내용은 내부에서 스크롤한다.
- 모달 포커스 가두기, 닫기·Esc, 실행 버튼으로의 포커스 복귀를 제공한다. 프로필 설정은 작성 중 입력을 보존한다.

## 화면 구성

상단 브랜드 → 제목·설명 → 기능별 영역 순서로 구성한다. 계정 유형별 메뉴는 [요구사항](../spec.md#로그인계정-유형)을 따른다. 정상·로딩·빈 결과·실패·재시도·저장 전 이탈 상태를 제공한다.

### 학생 홈

주요 탐색·개설 바로가기 카드와 학기 가능 시간 요약 카드를 넓은 화면에서는 좌우, 모바일에서는 위아래로 배치한다. 그 아래 참여 자율 모임·대학 주관 모임 미리보기를 기존 모임 카드로 보여주고 모임 관리의 전체 목록으로 연결한다. 각 데이터 영역은 독립적으로 로딩·빈 상태·실패·재시도를 표시한다. 표시 범위는 [홈 요구사항](../spec.md#학생-홈)을 따른다.

### 모임 탐색

열린 모임 카드가 중심이며 상단에 작은 유형 필터만 배치한다. 선택 즉시 적용하고 첫 페이지로 돌아간다. 정렬·참여 조건은 [FR-04](../spec.md#기능)를 따른다. 현재 페이지 개수·장소·시간을 표시한다. 유형에 맞는 결과가 없으면 전체 보기, 전체 목록이 비었으면 개설 메뉴를 안내한다.

### 모임 카드

탐색·관리·홈 미리보기에서 같은 카드를 사용한다.

- 은은한 유형 배지·우측 상단의 채워진 원/빈 원으로 인원을 표시하고 주제·장소·일정만 보여준다. 인원과 참여 상태는 보조 기술에도 전달한다.
- 카드 전체를 상세 링크로 사용한다. 모집·시간 겹침 설명과 별도 상세 버튼은 생략한다. 대학 주관 모임의 서류 현황·공지 대상 선택은 유지하고 선택 조작은 상세 이동과 분리한다.
- 불투명 표면·은은한 그림자를 사용한다. 참여 불가·시간 비겹침은 흐린 표면·약한 그림자로 구분하되 본문 대비·키보드 접근·상세 조회를 유지한다.
- 카드당 최소 400px과 카드 사이 간격을 확보하면 두 열, 그보다 좁으면 한 열로 배치한다. 별도 목록 스크롤 없이 페이지 전체를 스크롤하며 긴 제목·장소명은 줄바꿈한다.

### 대학 주관 모임

프로젝트 탐색과 소속 모임을 넓은 화면에서는 좌우, 모바일에서는 위아래로 배치한다. 현재 프로젝트는 표시선·체크로 구분한다. 등록 양식은 버튼으로 팝업을 열고, 모임별 입력을 세로형 카드로 구분한다. 공지 대상 선택은 카드 상단에 표시하며 좁은 결과 영역에서는 한 열을 유지한다.

### 시간표

위쪽 요일·왼쪽 교시/시작·종료 시간 축으로 정렬하고 같은 시간을 칸마다 반복하지 않는다. 프로필에서 요일 전체 선택·해제와 개별 선택을 제공한다. 흰 바탕·가벼운 행 구분선을 사용하고 선택 칸만 강조하며 중복 범례는 생략한다. 선택 상태는 체크와 색으로 구분하고 선택 교시 수를 표시한다. 좁은 화면은 시간 축을 고정한 표 내부 가로 스크롤로 조작 크기를 유지한다.

### 인증·개설

인증·개설은 좁은 폼과 전체 너비 주요 버튼을 사용한다.

- 개설은 모임 카드와 같은 한 장의 카드에 유형 배지·인원 표시·제목·장소·일정을 배치한다. 유형 배지는 왼쪽, 인원은 오른쪽에 배치하며 표시 크기에 맞춘 선택 영역을 누르면 기본 선택 메뉴를 연다. 제목은 표시 위치에서 직접 입력하고 장소는 같은 행의 선택 목록에서 검증된 장소를 바로 선택한다. 일정은 미정으로 표시하고 누르면 팝오버로 참여 후 확정 흐름을 안내한다. 유형·인원 선택과 일정 안내는 카드 크기를 바꾸지 않는다. 카드 아래에 개설 버튼을 둔다.
- 인증은 이메일 → 인증번호의 현재 단계를 표시하고, 발송 후 이메일 요약·변경·남은 시간·재발송을 제공한다.

### 프로필

- 학교·이메일 아래에 `가능 시간 · 내 정보 · 차단 · 계정` 설정 메뉴를 세로 목록으로 표시한다. 담당자도 같은 목록·팝업을 사용한다. 처음에는 상세 설정을 열지 않고 선택 시 [공통 팝업](#팝업)을 연다. 설정 해시가 있는 직접 링크는 해당 팝업을 연다.
- 시간표 불러오기는 버튼으로 팝업을 열고 저장 버튼은 입력 아래에 둔다. 시간표 위에 저장·미저장·저장 중 상태를 표시한다.
- 내 정보는 동의 전 입력 불가 이유를 안내하고 관심 주제는 추가·개별 삭제 가능한 태그로 입력하며 작성 중인 주제도 함께 저장한다.
- 로그아웃과 탈퇴 팝업을 구분한다.

### 함께 가능한 시간

위 시간표를 읽기 전용으로 재사용해 모두 가능한 칸만 체크·강조한다. 전체 교시 수를 제목 옆에 표시하고 공통 시간이 없으면 짧은 안내를 보여준다. 학기 교시 정보가 만료되면 요일·교시 텍스트로 표시한다.

### 모임 상세

- 공통 헤더 왼쪽에 목록으로 돌아가는 `<` 모양 아이콘 하나만 두고 중복 복귀 링크는 표시하지 않는다.
- 일반 모임은 확정 상태 → 참여자 → 조율 → 코멘트 순서다. 회고 게시판 우선 배치는 [회고 모임 정책](../spec.md#모임-분류회고-모임)을 따른다.
- 다른 참여자의 항목 전체를 버튼으로 사용해 안전 메뉴 팝업을 연다. 참여 행동은 넓은 화면의 보조 영역, 작은 화면의 상태 바로 아래에 둔다.
- 개인정보는 항목·행간을 구분한다. 가짜 모임·운영값은 표시하지 않는다.

## 자산
