# 모잇 브랜드 색상

## 선정 이유

학습 동료 탐색과 시간 조율에 어울리는 선명하고 차분한 인상을 목표로 한다. 파랑은 참여·확정·시간 선택의 공통 신호로, 따뜻한 아이보리는 화면 바탕으로 사용한다. 이는 디자인 방향이며 사용자 선호나 효과를 검증한 결과는 아니다.

## 색상 역할

구현 값의 원본은 [tokens.css](../tokens.css)다. 아래 HEX는 sRGB에서 반올림한 전달용 값이며 웹은 OKLCH 토큰을 사용한다.


| 토큰                 | 이름                  | HEX       | 용도                                       |
| ---------------------- | ----------------------- | ----------- | -------------------------------------------- |
| `--color-accent`     | 메인 / 모잇 블루      | `#2D56B6` | 주요 버튼·선택 시간·활성 필터·앱 아이콘 |
| `--color-paper`      | 바탕 / 웜 아이보리    | `#F9F6F0` | 페이지 바탕                                |
| `--color-surface`    | 표면 / 소프트 화이트  | `#FEFDFB` | 폼·입력 영역                              |
| `--color-paper-2`    | 보조 바탕 / 페일 블루 | `#E7EDF9` | 시간 안내·배지·빈 상태·아바타           |
| `--color-ink`        | 본문 / 잉크 네이비    | `#1B222E` | 제목·본문                                 |
| `--color-muted`      | 보조 글자 / 슬레이트  | `#515866` | 설명·시간·메타 정보                      |
| `--color-border`     | 폼 경계               | `#6C727C` | 입력·시간표 셀·보조 버튼 테두리          |
| `--color-rule`       | 구분선                | `#C6CBD4` | 목록·섹션의 장식 구분선                   |
| `--color-accent-ink` | 반전 글자             | `#FEFDFB` | 파란 버튼·선택 시간 위 글자               |
| `--color-focus`      | 포커스                | `#1B3F97` | 키보드 포커스 외곽선                       |
| `--color-error`      | 오류 / 브릭 레드      | `#9B1F1B` | 실패·위험 동작·입력 오류                 |

## 사용 기준

- 파랑은 주요 행동·선택·확정 표시 중심으로 사용한다. 넓은 영역은 밝은 바탕을 사용한다.
- 배지와 안내 패널은 페일 블루 바탕에 파랑 또는 본문 글자를 사용한다.
- 선택은 체크 표시·굵기·테두리와 함께, 오류는 오류 문구와 함께 표시한다.
- 폼 경계는 `border`, 장식 구분선은 `rule`을 쓴다. 장식 구분선을 입력 경계로 사용하지 않는다.
- 앱 아이콘은 메인 색상 바탕에 웜 아이보리 심볼을 사용한다.

## 대비 검증

WCAG 상대 휘도 공식으로 OKLCH를 선형 sRGB로 변환해 검증했다. 모든 색상은 sRGB 범위 안에 있다.


| 조합                    | 대비    | 기준  |
| ------------------------- | --------- | ------- |
| `accent-ink` / `accent` | 6.65:1  | 4.5:1 |
| `accent` / `paper`      | 6.27:1  | 4.5:1 |
| `accent` / `paper-2`    | 5.74:1  | 4.5:1 |
| `ink` / `paper`         | 14.90:1 | 4.5:1 |
| `muted` / `paper-2`     | 6.07:1  | 4.5:1 |
| `error` / `paper-2`     | 6.88:1  | 4.5:1 |
| `border` / `paper-2`    | 4.13:1  | 3:1   |
| `focus` / `paper-2`     | 8.10:1  | 3:1   |

본문·보조 글자·파랑·오류는 모든 밝은 바탕에서 4.5:1 이상, 폼 경계·포커스는 3:1 이상이다. 비활성 요소의 투명도와 실제 브라우저 렌더링은 위 수치 검증의 대상이 아니다.

## 앱 아이콘

- 원본: [app/icon.svg](../app/icon.svg), 64×64 좌표의 SVG.
- 두 개의 원은 사람, 연결된 둥근 어깨는 소문자 m과 함께 모이는 관계를 표현한다.
- 모잇 블루 바탕·웜 아이보리 심볼의 두 색상만 사용한다. 색상은 위 토큰의 전달용 sRGB 값을 따른다.
- 글자·그림자·그라데이션 없이 굵은 선과 충분한 내부 여백을 사용한다. 둥근 사각형 바깥은 투명하다.
- 최소 사용 크기 16px. 형태를 바꾸거나 심볼만 비균등하게 늘리지 않는다.
