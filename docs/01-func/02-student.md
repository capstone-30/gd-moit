# 학생 요구사항 — 모잇

[문서 안내](../../README.md#관련-문서) · [공통 요구사항](01-common.md) · [기관 요구사항](03-institution.md#대학-주관-모임제출-서류)

## 기능

인증 `C-FR-01`은 [공통 인증 정책](01-common.md#인증접근-권한)을 따른다.

| ID | 구현 조건 |
| --- | --- |
| S-FR-01 | 학기별 요일×교시 가능 시간 수정·재사용(모임별 개별 변경 불가). 미만료 타 학기에서 요일·교시 번호·시각이 일치하는 교시만 불러와 검토 후 저장한다. |
| S-FR-02 | 주제·유형·검증된 캠퍼스 장소·정원(개설자 포함 2~4명, 기본 3명 이상·2명 명시 선택)으로 시간 미정 모임을 개설한다. |
| S-FR-03 | 유형 필터로 미참여 모임을 탐색한다(본인 가능 시간 겹침 그룹 우선 → 비겹침 그룹, 그룹 내 최신순, [모임 카드](../02-uxui/01-design.md#모임-카드) 표시). 정원 내 즉시 참여하며 중복 참여를 막는다. |
| S-FR-04 | 상세에서 참여자 목록과 가능 시간 교집합을 표시한다. |
| S-FR-05 | 개설자가 교집합 시간을 확정하거나, 교집합이 없으면 대안을 제안해 전원 수락으로 확정한다([조율 규칙](#조율-규칙)). |
| S-FR-06 | 참여자 전용 새로고침 코멘트로 자기소개·장소 변경·지각·취소를 연락한다. |
| S-FR-07 | 모임/사용자 신고·차단·해제 및 개설자의 내보내기를 제공한다(상대 모임 숨김, 공동 모임에서 개설자가 차단 시 상대 강퇴·일반 참여자가 차단 시 본인 퇴장). |

## 모임 분류·회고 모임

- 모임 배지는 `모각공`·`커피챗`·`런치챗`·`회고`·`대학 주관`으로 구분한다.
- 회고 모임은 참여자 전용 회고 게시판(기존 코멘트 API·[S-FR-06](#기능) 권한·[개인정보 정책](01-common.md#개인정보-정책) 공유)을 일정·참여 영역보다 먼저 배치하며 시간 조율은 [조율 규칙](#조율-규칙)을 따른다.

## AI 작성 지원

연동 대기 중인 추가 요구사항이다([남은 작업](../03-tech/01-architecture.md#남은-작업과-리스크)).

- 모임 주제·유형 기반 대화 질문 제안과 본인 입력(경험·배움·다음 시도) 기반 회고 초안 정리를 선택적으로 제공한다(타인 정보·이메일·가능 시간 미전송, 실패·한도 도달 시 입력 보존).
- 외부 전송 전 항목·제공자·목적을 고지하고 초안은 영구 보관하지 않는다.

## 내비게이션·프로필

| 메뉴 | 경로 | 역할 |
| --- | --- | --- |
| 홈 | `/home` | 학생 첫 화면 |
| 모임 찾기 | `/meetings` | 미참여 자율 모임 탐색·참여 |
| 모임 열기 | `/meetings/new` | 자율 모임 개설 |
| 모임 관리 | `/meetings/manage` | 개설·참여 자율 모임 및 배정 대학 주관 모임 통합 조회(`/meetings/institution` 리다이렉트 포함) |
| 프로필 | `/profile` | 학기 가능 시간·선택 정보·차단·계정 관리 |

- 개설·참여 후 `/meetings/manage/:id`로 이동하며 유형별 기능(조율·코멘트·대학 공지/서류·회고)을 표시한다.

## 학생 홈

모임 찾기·개설 바로가기, 현재 학기 가능 시간 요약, 최근 참여 자율 모임·배정 주관 모임(각 최대 2개)을 표시한다.

## 시간표·이미지 불러오기

- 데모 교시는 월~금 1~12교시(1교시 `09:30~10:20`, 50분 수업·10분 휴식 간격, 12교시 `20:30~21:20`)다.
- 프로필에서 시간표 캡처(라이트·다크)를 브라우저 픽셀 분석(서버 미전송)해 빈 교시를 가능 시간으로 채운다.
- 업로드 전 눈금 형식(교시형: 첫 줄 1교시·20% 이상 겹침 / 시간형: 첫 줄 09:00·10분 이상 겹침)을 직접 선택한다. 상하단 UI는 제외하며 스크롤된 캡처나 격자 미인식 시 기존 선택을 유지하고 재캡처를 안내한다.
- 성공 시 제외된 수업 교시 수와 적용 취소·직접 수정·검토 후 저장을 제공한다(타 학기 시간 불러오기 시 이미지 적용 상태 초기화).

## 조율 규칙

- 확정·제안 날짜는 오늘부터 28일 이내이며 교시 요일과 일치해야 한다. 제안 수락 중에는 신규 참여를 막고 참여자·가능 시간 변경 시 제안을 취소한다.
- 교집합 확정은 참여자의 가능 시간 변경으로 해당 교시가 교집합에서 빠지면 미정으로 복귀한다. 대안 전원 수락 확정은 이후 가능 시간 변경에도 유지된다.
- 참여자가 1명이 되면 미정으로 복귀한다. 확정 모임 신규 참여는 해당 교시가 본인 가능 시간에 포함될 때만 허용한다.
