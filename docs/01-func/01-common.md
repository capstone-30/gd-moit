## 역할별 요구사항

역할별 기능·권한은 [기능 명세 목차](README.md)를 따른다.

## 범위

단일 캠퍼스 재학생의 모각공·커피챗·런치챗·회고 모임과 대학 담당자용 기관 시연 서비스다(개발·IT 외 주제도 허용).

### 우선순위

- 필수: 공통 인증 `C-FR-01`과 [학생 기능 S-FR-01~08](02-student.md#기능)(일정 축소 시 자유 주제를 고정 목록으로 대체 가능하며 사유·날짜 기록).
- 추가: 합성 기관 대시보드(B2B 시연), 대학 주관 모임 서류 제출·수신, [AI 작성 지원](02-student.md#ai-작성-지원).
- 여유시: 시연 쿠폰(비제휴 표시) · 확정 알림 · 참석 체크 · 세부 태그/추천.
- 제외: 공개 후기/신뢰도 · 강의실 매칭 · 사람 추천 · 외부인/졸업생 · 실시간 채팅 · 학사 연동 · 과금/정산 · 장기 운영 · 수요 수집/3명 알림.

## 로그인·계정 유형

### 인증·접근 권한

- 비로그인 `/`는 공개 랜딩, `/login`은 학교 도메인 이메일 OTP 인증 화면이다. 인증 후 저장된 계정 유형에 따라 학생은 `/home`, 담당자는 `/institutions`로 이동한다(유효 세션의 랜딩·로그인 접근도 동일 이동).
- 신규·기존 계정은 기본 학생이며, 담당자 지정·해제는 운영자 CLI([계정 유형 관리](../05-ops/02-operations.md#계정-유형-관리))로만 수행하고 사유 감사 기록 및 기존 세션 폐기를 동반한다.
- 비로그인 보호 화면 접근은 `/login`으로 이동하며 역할별 화면·API를 분리한다(본인 계정 조회·탈퇴·로그아웃 및 [주관 모임 역할별 기능](03-institution.md#대학-주관-모임제출-서류)은 공통 허용).
- `C-FR-01`: 학교 이메일 6자리 OTP(10분 만료, 5회 오입력 폐기, 재발송 60초, 주소당 시간당 5회·IP당 20회 제한, 계정 존재 여부 비노출).
- 단순 오입력·만료·폐기를 구분해 안내하고 만료·폐기 후 재발송 경로를 제공한다. 재발송 시 이전 번호 무효화와 번호·동의 확인 입력 초기화를 알린다.

### 내비게이션·프로필

계정별 메뉴는 [학생](02-student.md#내비게이션프로필)·[대학 담당자](03-institution.md#내비게이션프로필), 프로필 설정 직접 링크·팝업 동작은 [프로필 디자인](../02-uxui/01-design.md#프로필), 탈퇴는 [탈퇴·백업 복구](#탈퇴백업-복구)를 따른다.

## 로컬 로그인 데모

### 실행 제한·합성 데이터

- 개발 설정·루프백 주소·`_demo` DB에서만 허용하며 운영에서는 비활성화한다([로컬 로그인 데모](../../README.md#로컬-로그인-데모) · [시간표·이미지 불러오기](02-student.md#시간표이미지-불러오기)).
- `@tukorea.ac.kr` 합성 계정(담당자·학생 1·학생 2), 합성 학기·교시, 데모 장소(`TIP`·`중앙도서관`·`공학관E동`)를 제공하며 메일 발송 대신 화면에 OTP를 표시한다(만료·오입력·발송 제한·권한은 동일 적용).

### 탈퇴·백업 복구

- 탈퇴 시 본인 계정·시간·참여·코멘트·회고·신고·차단·개설 모임을 단일 트랜잭션으로 삭제하고 전 세션을 폐기하며 남은 모임의 인원·교집합을 재검증한다.
- 백업 잔존은 최대 7일이며 복구용 삭제 목록(`내부 ID·삭제 시각`)을 8일 보관해 복원 시 삭제·만료 처리를 재적용한 뒤 서비스를 연다.

### 신고·기관 접근

#### 신고 처리

- 최근 90일 미기각 신고가 서로 다른 신고자 3명에 도달하면 즉시 개설을 제한한다(기각·만료·탈퇴로 3명 미만 시 자동 해제). 운영자는 3영업일 내 검토·감사 기록한다.

#### 기관 정보 접근

- 기관 ESG 통계는 운영 DB와 분리된 **합성 데이터 시연만** 허용한다. 주관 모임에서는 제출 서류와 참여 순서 번호만 해당 담당자에게 공개하며 자율 모임·개별 시간·프로필·이메일은 비공개다.

### 동의·고지·서비스 종료

- 광고·추적·위치·연락처는 수집하지 않는다. 가입 전 `/privacy`에 항목·목적·기간·삭제법·쿠키·AWS 위탁/국외 이전 고지·연락처를 공개하며, 종료일([남은 작업](../03-tech/01-architecture.md#남은-작업과-리스크))에 가입 차단 및 원본 파기를 수행한다.

## 출시 조건

- 공개 프로필은 선택한 학과·입학 연도·관심 주제만 노출하고 모임 내에서는 참여 순서 번호를 사용한다(표시 이름·이메일·개별 가능 시간 비공개, [디자인](../02-uxui/01-design.md) 적용).
- 학교·도메인·학기·교시·장소·보관/삭제 동작·연락처·고지 검증 전까지 실제 가입을 차단한다.
