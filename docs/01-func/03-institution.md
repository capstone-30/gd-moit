## 내비게이션·프로필

| 메뉴 | 경로 | 역할 |
| --- | --- | --- |
| 홈 | `/institutions` | 주요 기능 바로가기 |
| 프로젝트 생성 | `/institutions/projects/new` | 활동 템플릿 선택·프로젝트 등록(생성 후 관리로 이동) |
| 프로젝트 관리 | `/institutions/meetings` | 프로젝트별 모임·공지·제출 서류 관리 |
| ESG 성과 | `/institutions/esg` | ESG 영역별 합성 활동 현황 시연 |
| 프로필 | `/institutions/settings` | 담당자 계정 관리 |

## 기관 시연

- `/institutions/esg`에서 환경(E)·사회(S)·거버넌스(G) 고정 합성 모임의 개설 월·유형별 모임 수·확정 수·참여 건수(모임별 인원 합)·충원율(`참여 건수 / 정원 합계`)을 시연한다(탄소 감축량 등 무근거 지표 미제공, 결과 없음은 `0` 표시).

## 대학 주관 모임·제출 서류

### 프로젝트·학생 배정

#### 프로젝트 생성·템플릿

- 소속 모임 경로는 `/institutions/meetings/projects/:id`다(미지정 기존 모임은 전체 모임 링크로 조회, [대학 주관 모임 디자인](../02-uxui/01-design.md#대학-주관-모임)).
- `빈 템플릿으로 시작`(기본 제출 요구 없음)과 [활동 템플릿 원본](../../shared/hosted-activities.ts)(생성 시 기본 제출 공지 게시, 포스터는 참고용)을 제공하며, 프로젝트 제목은 관리 화면에서 충돌 검증과 함께 수정할 수 있다.
- 담당자는 본인 프로젝트 안에 모임별 이름·학생 구성(2~4명)으로 한 번에 1~20개 주관 모임을 원자적으로 생성한다.

#### 보관·학생 배정

- 프로젝트는 생성 후 120일 보관하며 소속 모임 만료일은 프로젝트를 넘지 않는다(담당자 탈퇴 시 함께 삭제).
- 동일 학교 가입 학생 이메일로만 2~4명을 배정하며(중복·타교·담당자 불가, 이메일 응답 비공개), 담당자는 정원에 포함하지 않는다.

### 일정·모임 삭제

- 담당자는 본인 프로젝트 또는 개별 주관 모임을 확인 후 하위 참여·공지·제출 자료와 함께 단일 트랜잭션으로 삭제하고 복구용 삭제 목록에 기록한다.
- 배정된 학생 누구나 활동일·교시·검증 장소를 설정한다([조율 규칙](02-student.md#조율-규칙) 및 버전 충돌 적용, 담당자 설정 불가, 서류 1건 이상 제출 후 변경 불가).

### 공지·제출 요구

표시·조작은 [공지·제출 현황](../02-uxui/01-design.md#공지제출-현황)을 따른다.

- 프로젝트 공지는 보관 중인 전체 소속 모임에 일괄 게시·수정·삭제하고(삭제 시 복구용 삭제 목록 기록), 모임 상세 공지는 해당 모임에만 게시한다.
- 공지 작성·수정 시 서류 제출 요구(활동 보고서·활동비 사용 내역서 각 활성/해제)를 설정할 수 있다. 현재 제출 요구는 게시 순서상 마지막 제출 설정 공지를 따르며(공지 삭제 시 남은 마지막 설정 공지로 재계산, 없으면 해제), 기존 제출 자료는 보존한다.

### 서류 제출·열람

- 참여 학생은 활동일부터 활성화된 서류(활동 보고서: 내용·성과 / 활동비 사용 내역서: 오늘 이전 지출일·목적·원 단위 금액, 무지출은 빈 목록·0원)를 제출·재제출(충돌 시 입력 보존)한다. 요구된 서류가 모두 제출되면 완료로 표시하며, 참여 취소 시 본인 제출 자료도 삭제한다(지급·정산 기능 제외).
- 본인과 주관 담당자만 열람·CSV 다운로드(수식 실행 방지 적용)할 수 있으며, 담당자는 제출 설정 공지에서 참여 순서 번호별 제출 현황을 확인한다([공지·제출 현황](../02-uxui/01-design.md#공지제출-현황)).

### 보관·탈퇴

- 주관 모임·참여·공지·제출 자료는 활동일 후 30일(미정은 생성 후 90일, 최대 120일) 보관 후 만료 즉시 차단·일일 삭제한다(학생 탈퇴 시 본인 자료, 담당자 탈퇴 시 전체 삭제).
